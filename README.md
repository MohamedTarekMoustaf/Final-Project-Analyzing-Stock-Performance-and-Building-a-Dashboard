# Real Data Practice – SQLite Integration

## Overview
This project demonstrates data extraction, querying, and analysis from a SQLite database. It showcases SQL integration within Python and applies exploratory data analysis (EDA) on real-world data.

## Key Features
- Connects to SQLite database using Python
- Executes SQL queries directly within Jupyter notebooks
- Performs data cleaning and preprocessing
- Conducts exploratory data analysis (EDA)
- Visualizes insights using Matplotlib and Seaborn

## Requirements
- Python 3.x
- Libraries: `sqlite3`, `pandas`, `matplotlib`, `seaborn`

## How to Run
1. Install required libraries.
2. Open the notebook in Jupyter or Google Colab.
3. Follow the SQL query and data analysis sections step-by-step.
